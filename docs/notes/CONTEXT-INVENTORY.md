# Context and acknowledgement screens — full inventory

Every non-question screen in the flow, with every branch and the exact copy each branch produces.
Generated by reading `index.html` + `content.js` on 31 Jul 2026. Phase 4 works through this list.

Flow order (40 screens): hero → signup → q5 → **ack** → q6 → q2 → **ackname** → qphone → q1 → q3 →
qgoal → **ctxout** → qocc → qfield → qjtbd → **ctxba** → qskill → **ctxfeat** → qlevel → **ctxsci** →
qtime → qdaily → qnotif → **qsummary** → act → practice → score → loader → plan → letter → paywall.
IELTS side branch: qwhy → **ackielts** → qwhen → qband.
`ctxstat` exists but nothing routes to it.
